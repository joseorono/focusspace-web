## ❓ FAQ

**Q: Is it really free? What's the catch?**
A: No catch. FocusSpace is open source under MIT. No paid tier, no "pro" unlock, no upsell. If you want to support it, star the repo or contribute.

**Q: Will it delete my actual work history?**
A: No. FocusSpace only removes entries matching the categories *you enable*. Your research tabs, docs, and work sites stay untouched. You can also whitelist any domain to protect it explicitly.

**Q: Does this send my browsing data anywhere?**
A: Never. All processing happens locally. There are no servers, no analytics, no external API calls. You can verify this — the full source code is on GitHub.

**Q: How is this different from site blockers like StayFocusd or Cold Turkey?**
A: Blockers fight you in real time — they depend on your willpower to not bypass them. FocusSpace works *before* the impulse: it removes the triggers (tabs, history, autocomplete) that cause the distraction in the first place. Pair them if you want. They solve different problems.

**Q: Does it work on Firefox / Edge / Brave / Safari?**
A: Today it targets Chromium browsers (Chrome, Edge, Brave, Arc) via Manifest V3. Firefox support is on the roadmap — contributions welcome.

**Q: Can I customize what counts as a "distraction"?**
A: Yes, down to the keyword. Add your own, disable categories that don't apply, whitelist the sites that are work for you. Twitter might be toxic for one user and essential for another — FocusSpace doesn't judge.

**Q: Will it survive a Chrome update / can I trust it long-term?**
A: It's built on Manifest V3 (the current standard) using the Plasmo framework. And because it's open source, even if development slowed, you (or anyone) could fork and maintain it.

**Q: Can I contribute?**
A: Absolutely. Issues, PRs, and feature ideas are welcome on GitHub. This is built in public.

## 💡 Optimization Notes

**A/B Test Ideas:**
- **Headline A:** *"Your browser remembers every distraction. FocusSpace forgets them for you."* (memory angle)
- **Headline B:** *"One click. Thirty distracting tabs gone. Back to work."* (outcome angle)
- **Headline C:** *"The open-source focus extension that doesn't need your email."* (trust + OSS angle — great for HN/Reddit traffic)
- **CTA A:** `Add to Chrome — Free` (functional)
- **CTA B:** `Reclaim My Focus` (emotional, first-person)
- **Hero visual:** Animated "clean sweep" demo vs. static screenshot of the popup

**Conversion Tips Specific to FocusSpace:**
1. **Lead with the OSS angle on developer channels.** On HN, Reddit r/productivity, and Product Hunt, "open source, no tracking, no account" is the headline — not the feature list. Swap the H1 accordingly for those referral sources.
2. **Show the popup, not a marketing illustration.** This extension's UI is clean and uses glassmorphism well — a real screenshot builds more trust than a stock hero graphic.
3. **Add a 15-second screencast** above the fold showing one click → tabs vanish → Pomodoro starts. The product *demos* better than it describes.
4. **Include the category list as a visual grid** (NSFW, Gaming, Social, Dating, Entertainment, Health, Shopping, Travel). It's instantly understood and lets visitors self-identify their triggers.
5. **Put the GitHub star count and "MIT Licensed" badge near the primary CTA** — for the target audience (developers, power users), these convert harder than testimonials.
6. **Don't hide the FAQ.** This audience is skeptical of productivity tools. Objections-in-plain-sight beats hidden accordions.
7. **Avoid "AI-powered" anywhere.** This product's superpower is that it's *deterministic and local*. Lean into that — it's a differentiator right now.

**Tone Guardrails:**
- No shame-based copy ("stop wasting your life"). The target user already feels that. Be a guide, not a scold.
- No fake urgency / fake scarcity. It's open source — "limited seats" would destroy trust instantly.
- Keep the voice honest, technical-adjacent, and slightly dry. This audience smells marketing BS from 50 feet.
