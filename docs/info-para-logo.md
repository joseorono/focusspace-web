# Información para el Diseño del Logo - Clean My History

Este documento detalla las guías de diseño, colores y tipografía actuales del proyecto para servir de referencia en la creación del logo.

## Guías de Diseño (Design Guidelines)

El proyecto sigue una estética moderna y limpia basada en **Material Design** (específicamente la librería MUI). Algunos conceptos clave son:

- **Bordes Redondeados (Border Radius):** Se utiliza predominantemente un radio de `12px` para contenedores, tarjetas y pestañas. Los botones y elementos de control usan un estilo completamente redondeado o "píldora".
- **Efectos de Cristal (Glassmorphism):** El uso de desenfoque de fondo (`backdrop-filter: blur(12px)`) y bordes semitransparentes es común en la interfaz.
- **Simplicidad:** Se busca un diseño funcional y despejado, alineado con la utilidad de "limpieza" del historial.

## Paleta de Colores (Color Palette)

### Colores del Tema (MUI Theme)
Estos son los colores principales definidos en el sistema de temas:

- **Primario (Primary - Azul):**
  - Principal (Main): `#1976d2`
  - Claro (Light): `#60a5fa`
  - Oscuro (Dark): `#2563eb`
- **Secundario (Secondary - Morado/Violeta):**
  - Principal (Main): `#8b5cf6`
  - Claro (Light): `#a78bfa`
  - Oscuro (Dark): `#7c3aed`
- **Texto (Text):**
  - Primario: `#1f2937` (Modo claro) / `#f1f5f9` (Modo oscuro)
  - Secundario: `#6b7280` (Modo claro) / `#94a3b8` (Modo oscuro)

### Otros Colores y Colores "Hardcoded"
Colores utilizados en elementos específicos o iconos:

- **Gradientes de Iconos (Ej. Icono de escoba/limpieza):**
  - Mango: `#fcd34d` a `#f59e0b` (Amarillo/Naranja)
  - Cepillo: `#2563eb` a `#1e3a8a` (Azul vibrante a azul marino)
- **Acentos y Estados:**
  - Éxito (Success): `#030e18` (Fondo de notificación)
  - Error: `#d32f2f` (Rojo estándar)
  - Detalles adicionales en iconos: `#c084fc` (Púrpura claro), `#bfdbfe` (Azul muy claro), `#fef08a` (Amarillo pálido).
- **Fondos de Pestañas Seleccionadas:**
  - Azul translúcido: `rgba(59, 130, 246, 0.2)` o `rgba(25, 118, 210, 0.12)`.

## Tipografía (Typography)

La fuente principal del proyecto es **Roboto**, una tipografía sans-serif que equilibra la legibilidad con un aspecto tecnológico.

- **Familia tipográfica (Font Family):** `Roboto`, con caída a `sans-serif`.
- **Pesos utilizados (Font Weights):**
  - `300` (Light): Para textos ligeros.
  - `400` (Regular): Cuerpo de texto general.
  - `500` (Medium): Usado en notificaciones y énfasis moderado.
  - **`600` (Semi-bold):** Es el peso principal para **botones** y etiquetas de **pestañas (Tabs)**. Se recomienda considerar este peso para el logotipo o variaciones del mismo.
  - `700` (Bold): Para títulos y énfasis fuertes.

## Concepto Sugerido
Dado que el proyecto se llama "Clean My History", el logo podría jugar con la combinación de elementos de "tiempo/historial" (reloj, flechas circulares) y "limpieza" (escoba, destellos, claridad), utilizando principalmente los tonos de azul y morado de la paleta.
