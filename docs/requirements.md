
# Minimum Requirements:

- Navbar with Logo, fixed (visible after scrolling)
- Hero/Header
- Footer
- After the footer, a Copyright section linking to https://exologic.agency/ and https://elacreativa.vercel.app/ , with © 2026 All rights reserved. (display current year with Javascript)
- Screenshots are available in the folder: 'public/screenshots/'
- You can freely use the icons in 'public/icons'
- Use itshover.com icons like https://www.itshover.com/icons/airplane-icon, which were installed using "npx shadcn@latest add https://itshover.com/r/plug-connected-icon.json"

- We can use the Accent font (Cormorant) for sub-headings if needed.
- We should link to the Github repository of the Extension: https://github.com/joseorono/focus-space

- If users want to report an issue, they can do so at https://github.com/joseorono/focus-space/issues
- We are open to Contributions at the aforementioned repository.
