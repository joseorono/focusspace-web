# Images Directory

This folder stores image assets used by the application.

## Naming convention

Use clear, lowercase, kebab-case names:

- `landing-hero.webp`
- `feature-dashboard.png`
- `team-avatar-john-doe.jpg`

## Suggested formats

- Prefer `webp` for UI images.
- Use `svg` for logos and icons.
- Use `png` only when transparency or lossless quality is required.

## Notes

- Keep file names descriptive and stable.
- Avoid spaces and uppercase letters in file names.
- Optimize large images before committing.
